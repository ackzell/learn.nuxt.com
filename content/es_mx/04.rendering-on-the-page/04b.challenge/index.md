# Challenge!

::challenge
Haz que este medidor de nivel funcione
::

En este challenge pondrás a prueba tus habilidades de renderizado condicional.

En `src/App.vue` hay tres mensajes, pero se muestran todos al mismo tiempo. Tu tarea es hacer que la página muestre solo **uno** de ellos, dependiendo del `level` actual:

- Si el `level` es menor que `1`, muestra el primer mensaje.
- Si el `level` es menor que `3`, muestra el segundo mensaje.
- De lo contrario, muestra el tercer mensaje.

Usa las directivas `v-if`, `v-else-if` y `v-else` para encadenar estas condiciones, tal como lo hiciste en la lección anterior.

Cuando termines, usa el botón **Check my work** de abajo para verificar tu solución.
